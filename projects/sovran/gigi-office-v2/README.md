# sovran — gigi-office-v2

The canonical Gigi GIF set: 30 states, one constant office room, per-state
outfit color schemes. 512x512, 60 unique frames @24fps, seamless loops.

- `gifs/` — the 30 GIFs (`gigi_office_<state>.gif`)
- `sounds/` — 30 matching chiptune SFX (`gigi_<state>.wav`, 22050 Hz mono)
- `giphy_upload_results.json` — Giphy page URL per state (all 30 live)

States: idle, working, listening, speaking, thinking, success, alert, tired,
bitching, pushing_to_github, deploying, debugging, facepalm, laughing, smug,
drinking_coffee, eating_snack, dancing, sleeping, surprised, shrugging,
scheming, panic, salute, celebrating, gaming, rebooting, overheating,
flexing, goodbye.
